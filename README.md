1. установите docker desktop и запустите его;
2. подтяните файлы из корня репо к себе на устройство. у меня папка лежит по пути ```~/openmodelica-mac```, если будете менять название, то чекните в скриптах, но файлы должны лежать **внутри домашней директории**. файл ```om-vnc.sh``` запускает виртуальный сервер VNC и запускает в нем скрипт ```start-omedit.sh```. в свою очередь ```start-omedit.sh``` запускает уже OMEdit;
3. в терминале сделайте ```cd ~/openmodelica-mac && chmod +x om-vnc.sh start-omedit.sh``` &mdash; скрипты станут исполняемыми;
4. в терминале ```echo "alias om='\$HOME/openmodelica-mac/om-vnc.sh'" >> ~/.zshrc && source ~/.zshrc```. после этого вы сможете запускать openmodelica из терминала командой ```om``` из любой директории, контейнер соберется там, где вы находитесь;
5. запуск в терминале командой ```om```, OMEdit доступен, пока открыто окно терминале с запущенным контейнером. первый запуск может быть долгим;
6. откройте `http://localhost:6080/vnc.html?autoconnect=1&resize=scale` в браузере;
7. загрузите программу в интерфейсе OMEdit и проверьте, что все работает;
