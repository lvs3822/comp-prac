1. установите docker desktop;
2. подтяните файлы из корня репо к себе на устройство. у меня папка лежит по пути ```~/openmodelica-mac```, если будете менять название, то чекните в скриптах. файл ```start-omedit.sh``` запускает виртуальный сервер VNC и запускает в нем скрипт ```om-vnc.sh```. в свою очередь ```om-vnc.sh``` запускает уже OMEdit;
3. в терминале сделайте ```cd ~/openmodelica-mac && chmod +x om-vnc.sh start-omedit.sh``` &mdash; файлы станут исполняемыми;
4. проверьте наличие файла ```~/.zshrc``` (на маках он по идее есть по умолчанию), далее ```echo "alias om='\$HOME/openmodelica-mac/om-vnc.sh'" >> ~/.zshrc && source ~/.zshrc```. после этого вы сможете запускать openmodelica из терминала командой ```om``` из любой директории
5. из hw0 загрузите программу в интерфейсе OPEdit и проверьте, что все работает;
