1. установите docker desktop и запустите его;
2. подтяните файлы из корня репо к себе на устройство. у меня папка лежит по пути ```~/openmodelica-mac```, если будете менять название, то измените команду из п.4, но файлы должны лежать **внутри домашней директории**. файл ```om-vnc.sh``` запускается на маке: собирает образ и стартует контейнер. внутри контейнера автоматически выполняется ```start-omedit.sh``` &mdash; он поднимает виртуальный экран, VNC-сервер и OMEdit;
3. в терминале сделайте ```cd ~/openmodelica-mac && chmod +x om-vnc.sh start-omedit.sh``` &mdash; скрипты станут исполняемыми;
4. в терминале ```echo "alias om='\$HOME/openmodelica-mac/om-vnc.sh'" >> ~/.zshrc && source ~/.zshrc```. после этого вы сможете запускать openmodelica из терминала командой ```om``` из любой директории, контейнер запустится внутри неё;
5. запуск в терминале командой ```om```, OMEdit доступен, пока открыто окно терминала с запущенным контейнером. первый запуск может быть долгим (у меня было 10 минут);
6. откройте `http://localhost:6080/vnc.html?autoconnect=1&resize=scale` в браузере;
7. подтяните файл из hw0 к себе, загрузите его в интерфейс OMEdit и проверьте, что все работает;
